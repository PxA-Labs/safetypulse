# Getting help

| You want to… | Go to |
|---|---|
| Understand the method and results | The [Hugging Face article](https://huggingface.co/blog/purvansh01/safetypulse-safety-drift-monitor) and the [report](docs/report/REPORT.md) |
| Install and run the package | [README → Install and use](README.md#install-and-use) |
| Reproduce an experiment | [README → Reproducibility](README.md#reproducibility) and the `RUN_SUMMARY.md` of each run in `kaggle/executed/` |
| Report a bug or ask a question | [Open an issue](https://github.com/PxA-Labs/safetypulse/issues/new/choose) |
| Report a security problem or harmful content | Privately, as described in [SECURITY.md](SECURITY.md) |
| Request access to withheld artifacts (judges, reviewers) | See [docs/11_WITHHELD_ARTIFACTS.md](docs/11_WITHHELD_ARTIFACTS.md) |
