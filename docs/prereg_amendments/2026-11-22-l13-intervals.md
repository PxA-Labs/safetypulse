## What and why

The paper reports most of its evidence as small counts (63/63, 65/65, 11/12, 3/8, 17/17, 7/8, 0/2 control runs) and as
AUROCs over 6 to 31 models. Wilson intervals exist for the Table 2 counts (`docs/report/review_followups.md`, amendment
§3h) and for a few counts in `h2_lists.md`, `h6_safetune.md` and `h6_threshold_transfer.md`, but not for the Table 1
counts (11/12, 3/8, run-level 3/3 and 0/2), the without-Gemma counts (17/17, 7/8, 15/17, 0/8), the 8B-judge counts
(66/67, 43/43, 12/13, 3/7) or the per-family H6 AUROCs, and no interval for H6 accounts for the four families being
the real unit of replication. This analysis puts one interval next to every headline number in a single table.

## Methods (fixed now)

- Proportions: Wilson 95% score interval and Clopper-Pearson exact 95% interval (computed by bisection on the exact
  binomial CDF; no scipy). Counts are integers; every comparison is made on the integer counts, never on rounded rates.
- AUROC = P(unsafe score < safe score), ties count one half (as `tools/review_followups.py`).
  - H1 and H2+H3: bootstrap over whole runs within each condition (checkpoints of one run are not independent).
  - H6 pooled: (a) bootstrap over models, stratified by family (comparable to review_followups, which used B=2000);
    (b) **family-clustered** two-stage bootstrap: resample the 4 families with replacement, then the models within each
    drawn family with replacement. With only 4 families this interval is crude and is reported as such.
  - H6 by family: bootstrap over models stratified by label (resample unsafe and safe models separately, so both classes
    are always present), and the exact probability under random labelling (all C(n, k) assignments) of an AUROC at
    least as extreme as the observed one, to show what an AUROC of 1.00 on 6 models can and cannot establish.
  - B = 10000 everywhere, numpy `default_rng(20261122)`, percentile intervals.
- Lead times: bootstrap over runs (B = 10000) of the median lead, only where n ≥ 3 runs; with 3 runs the bootstrap
  median can take only the observed values, so this is reported as **descriptive** only.

## Difference from lane 14 (`docs/report/label_noise.md`)

Lane 14 resampled the 78 **prompts** to measure label noise (how unsafe labels and verdicts move with the prompt
sample). This analysis holds labels fixed and resamples **checkpoints, runs, models or families** to measure sampling
uncertainty of the reported rates and AUROCs. It does not repeat the prompt bootstrap and cites lane 14 for it.

## What will be reported

`tools/intervals.py` writes `docs/report/intervals.{json,md}`: one row per quantity above with the count, Wilson and
Clopper-Pearson intervals; one row per AUROC with the point value, each bootstrap interval named above, and the exact
random-labelling probability for the by-family AUROCs; the lead-time table marked descriptive. All rows are reported,
whatever they show. A proposed paper edit (one appendix table, no verdict change) goes to
`docs/report/workflow/paper_proposals/l13-intervals.md`. The script must run twice with identical output.
