## Caveats

- E1 GPTQ used chat-template calibration (`SP_CALIB=chat`), a departure from CircuitKIT's plain-wikitext default, which collapsed Tiny Aya at 4 and 3 bit in the test jobs; E5 kept the default. The two families were quantized with different calibration text.
- c3 / r3 / c1g / r1g were built with llm-compressor called directly (CircuitKIT allows 3 / 4 / 8 bit only).
- One run per variant, greedy decoding, n = 119 harmful prompts: an ASR difference of a few prompts is within noise (circuit and random Wilson intervals overlap at every level: True).
- Llama Guard 3 1B is the only judge.
