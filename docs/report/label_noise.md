# Label noise: prompt bootstrap of the unsafe labels and verdict stability (exploratory)

Generated by `tools/label_noise.py`; amendment `docs/prereg_amendments/2026-11-22-l14-label-noise.md`, written before the analysis. No new runs. **This is about label uncertainty from the 78-prompt sample, not a re-test:** the pre-registered verdicts (H1 confirmed, H2 confirmed, H3 refuted, H6 refuted) and the frozen thresholds stand.

Method: B = 2000 resamples of the 78 prompts (seed 20261122), one resample shared by every model and checkpoint so each is paired with its reference (step 0 or the aligned model). In each resample the unsafe labels (ASR > reference + 0.10) and the pre-registered metric and verdict rule are recomputed; `cis_sep`, the ‖ΔW‖ alarm steps and the thresholds are fixed. Flags: H6 from Job 9/14 (1B flags = Job 9's, the pre-registered labels); H1–H3 from the Job 8/10 regeneration (the Kaggle logs keep no per-prompt flags; see the last section). Intervals are 2.5–97.5 percentiles over resamples. A resample is centred on the observed prompts, so a flip probability measures sensitivity to the prompt sample, not the chance that the observed label is wrong.
