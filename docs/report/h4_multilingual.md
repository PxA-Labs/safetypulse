## Limitations

- Translation quality is not measured (no reference translations); length ratios and empty/capped counts are the only proxies. A poor translation can raise or lower ASR in a language independently of the model.
- The labels here are Llama Guard 3 8B on the 119 test prompts; the H3 monitor's ASR is Llama Guard 3 1B on the 78 dev prompts, so English unsafe labels here need not match H3's.
- 18 checkpoints from 3 seeds of one fine-tune (Alpaca) on one model; checkpoints within a run are correlated. Each ASR's Wilson 95% half-width is 0.055–0.086, comparable to the 10-point margin.
- The three seeds give the same step-0 ASR in every language (the step-0 LoRA checkpoint is at initialisation), so there is one baseline per language, and the 10-point margin starts from a different base rate in each (step-0 ASR from 0.101, French, to 0.168, Hindi, Spanish).
- The English alarm fired on all 15 later checkpoints, so these runs cannot show whether it would miss non-English drift that leaves English behaviour and the English refusal direction intact.
- Exploratory: no threshold, verdict or pass mark is set or changed.
