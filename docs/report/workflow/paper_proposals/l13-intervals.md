# Paper proposal (lane 13): intervals for every headline proportion and AUROC

Source of every number: `docs/report/intervals.md` / `intervals.json`, generated by `tools/intervals.py` (exploratory
amendment `docs/prereg_amendments/2026-11-22-l13-intervals.md`, commit `5b41d6b` on `wf/r2-lane13`, pushed before the
analysis commit `3aebf2a`). The script recomputes each point value from the raw rows and asserts it equals the paper's
number before computing any interval. No verdict or threshold changes. Not edited into `paper/main.tex`; for the
authors to accept or reject. If the branch is rebase-merged, the amendment SHA changes: cite the SHA on `main`.

What the intervals change in interpretation (all exploratory):

1. **Per-family H6 AUROCs.** A perfect ranking on Qwen3-4B (4 unsafe, 2 safe) arises under random labelling with
   probability 1/15 = 0.067; on Llama-3.2-3B (7, 3) 1/120 = 0.008; Llama-3.1-8B's 0.94 (6, 3) 2/84 = 0.024; Gemma's 0.50
   (2, 4) 9/15 = 0.60. A bootstrap interval at AUROC 1.00 collapses to [1.00, 1.00] and says nothing, so the exact
   probability is the informative quantity. The Qwen 1.00 is not distinguishable from chance at 5%.
2. **H6 pooled AUROC 0.83.** Resampling models within the four fixed families gives [0.68, 0.96] (as already in
   `review_followups.md`); treating the family as the unit (family-clustered bootstrap) widens it to [0.54, 1.00]. For
   the question "another model family", the lower end is near chance.
3. **`cis_circ` vs `cis_sep` pooled (0.94 vs 0.83).** Difference +0.10, family-clustered 95% [−0.14, 0.41]; ≤ 0 in
   23.6% of resamples. The text's "ranked better pooled" is not resolved by 31 models in 4 families.
4. **Small counts.** 7/8 safe models flagged without Gemma: Wilson [0.53, 0.98]; 0/8 for the spot-check [0.00, 0.32].
   H6 recall 11/12: Wilson [0.65, 0.98], so the pre-registered recall ≥ 0.8 criterion is met by the point value but not
   by the interval (the verdict rests on the FAIL rule and is unchanged). FAIL on safe recovered 3/8: [0.14, 0.69].
5. **Run-level vs checkpoint-level controls.** H1's 0/50 control checkpoints ([0.00, 0.07]) come from 0/2 control runs;
   checkpoints within a run are not independent, and at the run level the exact interval is [0.00, 0.84].
