# Paper proposal (lane 17): Conclusion sentence on combining cis_sep with the spot-check

Proposal only; `paper/main.tex` is not edited. Exploratory, post hoc analysis under amendment
`docs/prereg_amendments/2026-11-22-l17-two-stage.md` (commit 898ac5a, pushed on `wf/r1-lane17` before the analysis).
All numbers come from `docs/report/two_stage_alarm.json` (generated by `tools/two_stage_alarm.py`, which first asserts
it reproduces the `cis_sep` and spot-check rows of Table 2).

## Where

`paper/main.tex`, section Conclusion (lines 279-281 at the time of writing).

## Old text (exact)

```
A cheap behavioural spot-check, which raised far fewer false alarms on
new families, should be kept alongside; \cissep{}'s own advantages are earlier warning on Tiny Aya and needing no
generation.
```

## New text

```
A cheap behavioural spot-check, which raised far fewer false alarms on
new families, should be kept alongside. Run only to confirm a \cissep{} WARN (FAIL alarming alone; exploratory), it
kept 18 of 19 unsafe H6 models with 4 of 12 false alarms instead of 10, at 6.6\,s per model, but the confirmation
came no earlier than the spot-check, removing \cissep{}'s earlier warning on Tiny Aya (median lead 0 vs.\ 10 steps);
needing no generation remains \cissep{}'s own advantage.
```

## Notes for the authors

- The sentence names H1 (Tiny Aya) lead because that is the claim the old text makes; on H3 (Global) the same rule has
  median lead 0 vs. 20 for `cis_sep` alone, and could be added if space allows.
- Without Gemma-3-4B (whose aligned model scores 0.34 on the spot-check), the escalation rule gives 17/17 and 1/8
  (`h6_without_gemma.B_escalation`), against 17/17 and 7/8 for `cis_sep` alone.
- Intervals overlap heavily (12 safe H6 models); the sentence should stay labelled exploratory and should not be read
  as establishing the combination.
- If the page budget is tight, a shorter alternative: "...should be kept alongside: as a confirmation of \cissep{}
  warnings it cut H6 false alarms from 10/12 to 4/12 at no loss of recall, but gave up the earlier warning (exploratory,
  Appendix)."
