## 1. Main finding: how the integration branch is merged decides what breaks

- `origin/main` (`eb07db8`) and `origin/stage2/wf-integration` (`9d99ae4`) have diverged: merge base `725551d`; 140
  commits are only on the integration branch, 3 only on main (`15a248e`, `15d359a`, `eb07db8`). `15a248e` and
  `15d359a` are the PR #160 rebase copies of the integration commits `1dcc6d3` and `6ab84a7` (`git cherry` marks both
  as already applied; `git diff 1dcc6d3 15a248e` and `git diff 6ab84a7 15d359a` are empty).
- **Merge commit ("Create a merge commit")**: every SHA in the tables below stays reachable from main. Nothing has to be
  replaced except the four superseded pre-rebase SHAs, which should be cited by their main copies anyway.
- **Rebase-merge or squash**: all 31 integration-only commits get new SHAs (squash: they vanish into one).
  Every citation of them in records, cards, proposals and job scripts then points to a commit that main does not
  contain; it survives on GitHub only while a branch or tag still contains it. The integration branch is also full of
  `--no-ff` merge commits, which a rebase-merge linearises. **Recommendation: merge with a merge commit**, and before
  any branch clean-up push a tag for each run pin (`543ba6f`, `4ef5645`, `e2fb4a1`, `eacb3a3` and the launched-script
  commits), because `raw.githubusercontent.com/PxA-Labs/safetypulse/<sha>/...` in the job scripts needs the commit to
  stay fetchable.
- `paper/main.tex:326` on the integration branch still cites `1dcc6d3`; main already cites `15a248e` (`eb07db8`). The
  only difference between the two `main.tex` files is that line. `consolidated.patch` applies to main's `main.tex` with
  **hunk 10 of 10 failing** (`patch -p0 --dry-run`): that hunk carries M1 (`1dcc6d3` -> `15a248e`, already done on
  main) and the `1cb8ea0` rewording, which must then be applied by hand. Proposals whose "old text" quotes `1dcc6d3`
  (e.g. `l02-h6-testsplit.md:49,56`, `l03-third-judge.md:61,66`, `l18-limitations-ethics.md:38`, `l18-format.md:77-100`)
  will not match main's text verbatim.
