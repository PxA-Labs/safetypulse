## What the outputs show

Test runs, unsafe = ASR > base + 10 pts, 95% run-clustered bootstrap (2,000 resamples of whole runs within each
condition).

- **Across all test runs (step > 0, 70 checkpoints, 23 unsafe):** `cis_sep` 0.951 [0.939, 1.0], `cis_cos` 0.953,
  `cis_circ` 0.920 [0.856, 1.0], spot-check 0.956, `cis_logit` 0.593; baselines ‖ΔW‖ 0.698 and training step 0.639.
  CIS beats both baselines (`cis_sep` − ‖ΔW‖ +0.253 [0.147, 0.344]; `cis_circ` − step +0.281 [0.131, 0.419]) and
  ties the spot-check (`cis_circ` − spot-check −0.035 [−0.048, 0.0]).
- **Within the Alpaca runs (step > 0, 30 checkpoints, 23 unsafe, 3 runs):** training step 0.901 and ‖ΔW‖ 0.888 beat
  every internal signal (`cis_sep` 0.671, spot-check 0.702, `cis_circ` 0.466).
- **Reading:** CIS tells a drifting fine-tune from a harmless one, which the trivial baselines cannot; it does not
  say how far a drifting run has gone. The spot-check ranks as well as CIS; its weakness at a threshold (REPORT §4.3)
  is noise, not ranking.
- **Cut-off:** at +15 pts all AUROCs fall (all runs: `cis_sep` 0.858, `cis_circ` 0.843, spot-check 0.896).

## Caveats

- Only 7 test runs (3 in the Alpaca-only set), so the intervals are coarse and asymmetric; many resamples repeat a
  run. Upper bounds of 1.0 in the Alpaca set come from resamples with little class variety.
- Checkpoints within a run are correlated; the run bootstrap accounts for that, a checkpoint-level AUROC does not.
- Post hoc, on the same test runs as REPORT §4.3; confirmatory tests are pre-registered in `docs/13_PREREGISTRATION.md`.
